## 2. Router0 Configuration

```cisco
enable
configure terminal

interface gigabitEthernet 0/0
 ip address 192.168.10.1 255.255.255.0
 no shutdown
exit

end
```

## 6. Verification

### Connectivity Tests

```text
ping 192.168.10.1
ping 192.168.10.2
ping 192.168.10.3
```

All required connectivity tests were successful.

### RADIUS Authentication Test

Correct credentials:

```text
Username: jihad
Password: 12345
Result: Authentication Successful
```

Incorrect credentials:

```text
Username: jihad
Password: wrong123
Result: Authentication Failed
```

This confirms that wireless authentication is being performed through the centralized RADIUS server.
